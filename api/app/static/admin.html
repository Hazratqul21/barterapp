Firebase — holat

1. Server kaliti — xabar yuborish uchun

Firebase konsolida: Project settings → Service accounts → Generate new private key. Yuklab olingan JSON faylni tanlang yoki mazmunini pastga qo'ying.

⚠️ Kalit saqlangandan keyin qayta o'qib bo'lmaydi — API faqat «sozlangan» deb javob beradi. Bu ataylab: panelga kirgan har kim uni ko'chirib olib keta olmasin. Almashtirish uchun yangisini qo'yish yetarli.

2. Ilova parametrlari — xabar qabul qilish uchun

Firebase konsolida ilovangizni tanlang → SDK setup and configuration. Bu qiymatlar maxfiy emas.

3. Buni panel qila olmaydi

APNs kaliti — iOS'ga push yuborish uchun Apple Developer hisobingizdan .p8 kalit olib, uni Firebase konsoliga yuklash kerak (Project settings → Cloud Messaging → APNs Authentication Key). Bu Google va Apple o'rtasidagi bog'lanish — server undan o'tmaydi.

Push entitlement — Runner.entitlements ga aps-environment qo'shilishi va ilova shu bilan qayta imzolanishi kerak. Bu ilova ichiga kompilyatsiya qilinadi, ya'ni yangi reliz talab qiladi.

Ikkalasi bir marta qilinadi. Shundan keyin kalit almashtirish faqat shu sahifadan bo'ladi.
