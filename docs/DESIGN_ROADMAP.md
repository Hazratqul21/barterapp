# BarterApp: Material 3 Design & Google-Quality Roadmap

Ushbu roadmap loyihaning dizayn darajasini **Google Material 3 (M3)** standartlariga va yuqori darajadagi mobil ilovalar sifatiga olib chiqish, shu bilan birga iOS va Android platformalarida mukammal ishlashini ta'minlash uchun ishlab chiqildi.

---

## 0-Bosqich: Multi-platform Health (Baseline) - ✅ TUGALLANDI
Ilova barcha platformalarda barqaror va native xususiyatlarga ega.
- [x] **iOS Network Security:** Real qurilmalar uchun tarmoq sozlamalari (`Info.plist`).
- [x] **Privacy Permissions:** Kamera va Galereya uchun professional o'zbekcha tavsiflar.
- [x] **Safe Area Management:** Har qanday ekran o'lchami (Notch, Home indicator) uchun adaptiv padding.
- [x] **Platform Physics:** iOS uchun `BouncingScrollPhysics` barcha asosiy listlarda.

## 1-Bosqich: Foundation (Tizim asosi) - ✅ TUGALLANDI
Loyiha mustahkam va zamonaviy Material 3 poydevoriga ega.
- [x] **Global FAB Styling:** Google-style aylana (Circle) shaklidagi FAB.
- [x] **Tonal Palettes (v1.2):** Ranglar ierarxiyasi "Surface Container" tizimiga to'liq o'tkazildi.
- [x] **Typography Hierarchy:** `Rubik` va `Manrope` fontlarining M3 ierarxiyasiga bog'lanishi.

## 2-Bosqich: Motion & "The Feel" (Harakat) - ✅ TUGALLANDI
Google ilovalarining eng kuchli tomoni — bu premium animatsiyalar.
- [x] **Container Transform:** E'lon kartasidan detallarga o'tishda silliq "OpenContainer" animatsiyasi.
- [x] **Staggered Animations:** Ro'yxat elementlarining birin-ketin kirib kelishi.
- [x] **Soft Grouping:** Chat pufakchalarining Google-uslubidagi yumshoq dizayni.
- [x] **Haptic Feedback:** iOS Taptic Engine va Android vibratsiyasining har bir interaksiyada ishlatilishi.

## 3-Bosqich: Adaptive & Canonical Layouts - 🔄 DAVOM ETMOQDA
- [x] **Content Constraints:** Katta ekranlarda kontent 720px bilan cheklangan (Google Desktop uslubi).
- [x] **M3 Navigation Rail:** Web va Desktop versiya uchun zamonaviy yon navigatsiya paneli.
- [ ] **Canonical Layouts:** Planshetlar uchun real "List-Detail" ko'rinishini joriy qilish.

## 4-Bosqich: Polish & UX (Sayqallash) - ✅ TUGALLANDI
- [x] **Polished Input:** Chat va formalardagi kiritish maydonlarining "Floating" va "Tonal" ko'rinishi.
- [x] **Form Transitions:** Ko'p bosqichli formalardagi (Create Listing) silliq o'tish animatsiyalari.
- [x] **Splash & Intro Polish:** Brendning silliq nafas olish (Breathing) animatsiyalari.
